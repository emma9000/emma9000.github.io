GIS Land Data Digitisation & Management System

Desktop system for digitising and managing land survey data, supporting provincial-level mapping and land information workflows.

Project Overview

Sole developer on the Gansu Province Third National Land Survey Digitisation & Management System — a C/S desktop application for digitising and managing provincial land survey data. I owned the full development effort independently, including on-site technical support at the client's location.

Built with C# WinForms and DevExpress for the UI, backed by an Oracle database with partitioned storage and backup workflows. Used NPOI for Excel import/export, and Access dictionary tables for reference data lookups.

This project sits at the intersection of a surveying/GIS background and software engineering — a combination most backend engineers don't have

Many Tongues

Real-time transcription and translation platform for community organisations. Independently designed, built, and operated, in active use by 20+ organisations across New Zealand translating into 60+ languages.

Live Link

Project Overview

Attendees scan a QR code and follow the live speech in their own language on their phone. No app, no login, no download required. The stack is a Next.js 15 front end, with a standalone Node.js transcription microservice talking to Deepgram Nova-3 for streaming ASR, Redis for the real-time Pub/Sub and sequencing layer, and Postgres (Supabase) for persistence. It's deployed via Docker Compose behind Caddy on a Linux VPS in Singapore, through a self-configured CI/CD pipeline. In production, live captions stay under 1 second and translation under 3 seconds.

The hardest problem wasn't the translation engine itself. Deepgram's streaming ASR routinely split one spoken sentence into several fragments, leaving the translator with no context. I built a buffering layer that holds fragments until a sentence actually ends, using punctuation, a 3-second silence gap with a 30-character minimum, and a 150-character ceiling as a safety valve.

I also solved keeping subtitle ordering intact across WebSocket reconnects, using Redis's atomic HINCRBY for sequencing.

Multiple AI models sit behind an Adapter and Strategy design, each chosen by task performance, with circuit-breaker failover (per-call timeouts, error-rate tripping, and backoff recovery probes), so a model outage degrades translation instead of stopping it. I also handled a production security incident end to end, patching a vulnerable Next.js version and hardening the deployment, and monitoring logs and backups.
